## Отличия от первоначального кода

Из 132 файлов исходного манифеста изменены только:

1. `backend/backend/settings.py`: удалены встроенные значения ключа Django, пароля БД, SMTP-пароля и личный SMTP-адрес; настройки читают окружение. `SECRET_KEY` и `DB_PASSWORD` обязательны. DEBUG по умолчанию False, разрешённые хосты — localhost/127.0.0.1, почта — dummy backend.
2. `docker-compose.yml`: секреты подставляются из окружения/локального `.env`; нужные настройки передаются backend. Параметры БД теперь считываются Django. Это устраняет конкретное расхождение переменных, но не доказывает исправность всего запуска.
3. `.gitignore`: добавлены исключения секретных и локальных файлов.
4. `README.md`: вместо пустого файла добавлены описание проекта, ссылки и ограничения.

Дополнительно создан `backend/.dockerignore`, чтобы локальные секреты и данные не попадали в контекст backend-образа. Прикладные обработчики, сериализаторы, модели и клиенты не исправлялись. Старые секреты не отзывались и не проверялись на действительность; это действие остаётся за владельцем.

## Дополнительная проверка секретов

По отдельному запросу пользователя выполнен Gitleaks **8.30.1**, официальный архив для macOS arm64 сверён с SHA-256 из checksum-файла релиза. Использованы стандартные правила без собственных исключений; `gitleaks:allow`-комментарии игнорируются, значения находок маскируются.

Проверены рабочие файлы, индекс Git перед коммитом и вся доступная Git-история. Во время исходного прогона история содержала только пустой начальный коммит; поэтому исторический скан обработал 0 байт diff. Рабочие файлы и индекс проверялись отдельно — это существенно для нового репозитория. Каждый прогон завершился с кодом 0 и без находок.

Команды для повторения из корня репозитория с установленным Gitleaks 8.30.1:

```bash
gitleaks dir . --config task_27_09/evidence/gitleaks-default.toml --redact=100 --ignore-gitleaks-allow --max-archive-depth 2 --no-banner
gitleaks git . --pre-commit --staged --config task_27_09/evidence/gitleaks-default.toml --redact=100 --ignore-gitleaks-allow --no-banner
gitleaks git . --log-opts=--all --config task_27_09/evidence/gitleaks-default.toml --redact=100 --ignore-gitleaks-allow --no-banner
```

Исходные отчёты до коммита: [файлы](gitleaks-files.json), [индекс](gitleaks-staged.json), [история](gitleaks-history.json). Они содержат пустые массивы находок. Кроме сканера выполнена отдельная проверка отсутствия известных секретов исходного архива во всех подготавливаемых к коммиту байтах. Ни один сканер не гарантирует обнаружение произвольного неизвестного секрета; реальные учётные данные для проверки не использовались.
