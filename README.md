# HelpHealth

Учебная курсовая работа: Android-приложение пациента, web-интерфейс врача и backend для мониторинга здоровья. Исходный проект предоставлен из каталога `Olga-Belova-oibelova-main`; авторство курсовой указано в [project.md](task_27_09/project.md).

## Состав

- `HealthMonitor/` — Android/Kotlin.
- `frontend/` — React.
- `backend/` — Django REST Framework.
- `docker-compose.yml`, `nginx/` — исходные файлы развёртывания.
- `AGENTS.md` — карта кода и инструкции для будущей работы.
- `task_27_09/` — исходное задание и результат от 27.09.2026.
- [project.md](task_27_09/project.md) — заполненный документ по Secure SDLC и критериям курса.
- [evidence/](task_27_09/evidence/) — статические свидетельства, инвентаризация, исходный манифест и скрипт их сбора.

## Публикационная подготовка

Перед первым добавлением исходников в Git убраны встроенные секреты Django, БД и SMTP, а также личный адрес отправителя. Настройки читают переменные окружения; по умолчанию DEBUG выключен, хосты ограничены localhost, отправка почты отключена. Compose передаёт необходимые настройки. Файлы окружения, данные выполнения и локальные настройки IDE исключены из Git; окружение и данные также исключены из контекста backend Docker. Остальная прикладная логика сохранена.

Для подготовки конфигурации скопируйте `.env.example` в `.env`, самостоятельно создайте случайные `SECRET_KEY` и `DB_PASSWORD`. Например, каждое значение можно получить командой `python3 -c 'import secrets; print(secrets.token_urlsafe(48))'`. Для Compose корневой `.env` используется при подстановке переменных. При запуске Django вне Compose нужные переменные должны быть экспортированы в окружение процесса: сам Django этот файл не загружает.

Полная сборка и запуск не проверялись. Включение SMTP требует явной настройки; при dummy backend письма подтверждения не доставляются. Конфигурация адресов клиентов и Ollama всё ещё требует подготовки стенда. Изменения для публикации не устраняют выявленные проблемы авторизации, выдачи данных и PDF/LLM-потока. Это исходники учебного прототипа, не готовый production-выпуск.

## Как читать свидетельства

`task_27_09/evidence/snapshot.sha256`, `inventory.json` и `source-review.md` относятся к первоначальному снимку из Downloads, до публикационных изменений. Их номера строк и хеши не описывают все текущие файлы репозитория. Они сохранены как исходная точка анализа; значения секретов в выдержках скрыты. [Публикационная проверка](task_27_09/evidence/publication-check.md) отдельно описывает изменения и выполненные проверки этой копии.

Обнаруженные в первоначальном архиве потенциально действующие секреты необходимо отозвать или заменить владельцу: удаление из публикуемой копии не выполняет их отзыв.
